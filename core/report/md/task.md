# Лабораторные работы по теории графов

## Лабораторная работа № 1

1. Сформировать случайным образом связный ациклический ориентированный граф с введённым пользователем количеством вершин в соответствии с заданным распределением. Параметры распределения задаются как константы и подбираются экспериментально. Распределение выбрать из справочника Вадзинского: реализовать приведённую блок-схему либо генерирующую формулу. Генерация выполняется по степеням вершин. В зависимости от дальнейшего задания используется ориентированный граф либо полученный из него неориентированный граф. Допускается консольная реализация.
2. Посчитать эксцентриситеты вершин, выделить центр графа и диаметральные вершины.
3. Реализовать метод Шимбелла для весовой матрицы, сгенерированной с помощью заданного распределения. Пользователь вводит количество рёбер пути. Результат представить в виде матрицы минимальных и/или максимальных путей. При генерации весовой матрицы предусмотреть три режима по выбору пользователя:
   - только положительные значения;
   - только отрицательные значения;
   - смешанные значения.
4. Определить возможность построения маршрута между двумя заданными пользователем вершинами и указать количество таких маршрутов.
5. Реализовать пользовательское меню.

## Лабораторная работа № 2

1. Для графов, случайно сгенерированных в предыдущей работе, реализовать следующий алгоритм варианта:
   - **d)** поиск точек сочленения графа.
2. Сгенерировать весовую матрицу с положительными либо отрицательными весами по выбору пользователя и найти кратчайший путь между двумя выбранными вершинами. Вывести расстояние и путь в виде последовательности вершин. Для алгоритмов Дейкстры и Беллмана–Форда необходимо вывести вектор расстояний, для алгоритма Флойда–Уоршелла — матрицу расстояний.

   Алгоритм варианта:
   - **h)** алгоритм Дейкстры для отрицательных весов.
3. Сравнить скорость работы реализованных алгоритмов по количеству итераций.

## Лабораторная работа № 3

1. На основе сгенерированного ориентированного графа случайным образом получить матрицы пропускных способностей и стоимостей.
2. Для полученного графа найти максимальный поток по алгоритму Форда–Фалкерсона либо другому алгоритму из перечисленных в лекции.
3. Вычислить поток минимальной стоимости заданной величины. В качестве величины потока использовать

   $$
   \left\lfloor \frac{2}{3}\,\text{maxFlow} \right\rfloor,
   $$

   где `maxFlow` — найденный максимальный поток. Использовать ранее реализованный алгоритм Дейкстры, Беллмана–Форда либо Флойда–Уоршелла.

## Лабораторная работа № 4

1. Для заданных неориентированных графов, случайно сгенерированных в первой работе, найти число остовных деревьев с помощью матричной теоремы Кирхгофа.
2. Построить минимальный по весу остов сгенерированного неориентированного взвешенного графа.

   Алгоритм варианта:
   - **a)** алгоритм Краскала.

   Полученный остов закодировать с помощью кода Прюфера и декодировать. При кодировании обязательно сохранять веса рёбер.
3. На исходном графе и полученном остове по выбору пользователя реализовать следующий алгоритм варианта:
   - **e)** нахождение максимального независимого множества рёбер.

   Материал по алгоритму Эдмондса: [Edmonds's Blossom Algorithm](https://algorithms.discrete.ma.tum.de/graph-algorithms/matchings-blossom-algorithm/index_en.html).

## Лабораторная работа № 5

1. Для заданных неориентированных графов, случайно сгенерированных в первой работе, проверить, является ли граф эйлеровым. Если граф не является эйлеровым, модифицировать его и вывести сведения обо всех изменениях. Построить эйлеров цикл.

   **Алгоритм приведения графа к эйлерову виду:**

   1. Найти все вершины нечётной степени.
   2. Пока существуют нечётные вершины:
      - выбрать две вершины нечётной степени `u` и `v`;
      - если ребро `(u, v)` существует, удалить его;
      - иначе добавить ребро `(u, v)`.

   **Патч для сохранения связности:** перебираем пары нечётных вершин и перед удалением ребра проверяем наличие обходного пути. Мост удаляется только в том случае, если пользователь явно разрешил получить несвязный результат.

   После каждой операции степени вершин `u` и `v` меняют чётность, поэтому количество вершин нечётной степени уменьшается на два. Поскольку количество нечётных вершин в графе всегда чётно, процесс завершается за конечное число шагов.
2. Для заданных неориентированных графов, случайно сгенерированных в первой работе, построить минимальный остов алгоритмом из четвёртой лабораторной работы. На основе остова для чётного варианта:
   - получить фундаментальную систему разрезов и вывести её на экран;
   - получить остальные разрезы из фундаментальных с помощью операции симметрической разности; номера объединяемых разрезов вводит пользователь.
