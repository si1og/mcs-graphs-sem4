\section{Постановка задачи}

Цель работы: разработать единый программный комплекс с текстовым пользовательским интерфейсом для генерации, анализа и преобразования графов, объединяющий алгоритмы теории графов, реализованные в ходе выполнения пяти лабораторных работ.

Задачи.
\begin{enumerate}
    \vspace{1em}
    \textbf{Первая лабораторная работа:}
    \item сформировать случайным образом связный ациклический ориентированный граф в соответствии со смещённым распледеления Вейбулла с заданным пользователем количеством вершин;
    \item реализовать генерацию весовой матрицы в соответствии со смещённым распределением Вейбулла с положительными, отрицательными или смешанными весами при заданном пользователем количестве рёбер;
    \item посчитать эксцентриситеты вершин;
    \item выделить центр графа;
    \item определить диаметральные вершины;
    \item реализовать метод Шимбелла для сгенерированной весовой матрицы при заданном пользователем количестве рёбер;
    \item выводить максимальный или минимальный путь, полученный методом Шимбелла, в виде весовой матрицы;
    \item определить возможность построения маршрута между двумя заданными пользователем вершинами и посчитать количество таких маршрутов;
    \item реализовать пользовательское меню;

    \vspace{1em}
    \textbf{Вторая лабораторная работа:}
    \item найти точки сочленения в сгенерированном графе;
    \item найти кратчайший путь между выбранными вершинами с помощью алгоритма Дейкстры для отрицательных весов, вывести расстояние, вектор расстояний и последовательность вершин пути;
    \item сравнить скорость работы алгоритмов по количеству итераций;

    \vspace{1em}
    \textbf{Третья лабораторная работа:}
    \item сформировать случайным образом матрицу пропускных способностей в соответствии со смещённым распледеления Вейбулла на основе сгенерированного ориентированного графа;
    \item сформировать случайным образом матрицу стоимостей в соответствии со смещённым распледеления Вейбулла на основе сгенерированного ориентированного графа;
    \item найти максимальный поток для полученной матрицы пропускных способностей по алгоритму Форда--Фалкерсона;
    \item вычислить поток минимальной стоимости величины $\left\lfloor 2 / 3 \cdot \text{max} \right\rfloor$, здесь $\text{max}$~--- найденный максимальный поток;

    \vspace{1em}
    \textbf{Четвёртая лабораторная работа:}
    \item найти число остовных деревьев неориентированного графа с помощью матричной теоремы Кирхгофа;
    \item построить минимальный по весу остов для неориентированного взвешенного графа алгоритмом Краскала;
    \item закодировать остов кодом Прюфера с сохранением весов рёбер и декодировать его;
    \item найти максимальное независимое множество рёбер на исходном графе и полученном остове по выбору пользователя;

    \vspace{1em}
    \textbf{Пятая лабораторная работа:}
    \item проверить, является ли неориентированный граф эйлеровым;
    \item при необходимости модифицировать граф с сохранением связности и вывести сведения о выполненных изменениях;
    \item построить эйлеров цикл;
    \item построить минимальный остов алгоритмом Краскала;
    \item получить фундаментальную систему разрезов и вывести её на экран;
    \item получить остальные разрезы из фундаментальных с помощью операции симметрической разности для выбранных пользователем разрезов.
\end{enumerate}
