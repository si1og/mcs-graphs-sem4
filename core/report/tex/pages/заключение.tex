\section*{Заключение}
\addcontentsline{toc}{section}{Заключение}

В ходе выполнения лабораторных работ разработана консольная программа для генерации и исследования графов. Реализованные методы объединены общими классами графа и матрицы, а их работа проверена на сгенерированных графах.

В результате выполнены следующие задачи.
\begin{enumerate}
    \vspace{1em}
    \item[] \textbf{Первая лабораторная работа:}
    \item реализована генерация связного ациклического ориентированного графа в соответствии со смещённым распределением Вейбулла;
    \item реализована генерация весовой матрицы с положительными, отрицательными или смешанными весами в соответствии со смещённым распределением Вейбулла;
    \item реализовано вычисление эксцентриситетов вершин;
    \item реализовано определение центра графа;
    \item реализовано определение диаметральных вершин;
    \item реализован метод Шимбелла для сгенерированной весовой матрицы;
    \item реализован вывод максимальных и минимальных весов маршрутов, полученных методом Шимбелла, в виде весовой матрицы;
    \item реализованы проверка возможности построения маршрута между заданными вершинами и подсчёт числа таких маршрутов;
    \item реализовано пользовательское меню;

    \vspace{1em}
    \item[] \textbf{Вторая лабораторная работа:}
    \item реализован поиск точек сочленения сгенерированного графа;
    \item реализован поиск кратчайшего пути между выбранными вершинами модифицированным алгоритмом Дейкстры с выводом расстояния, вектора расстояний и последовательности вершин;
    \item выполнено сравнение алгоритмов по числу итераций;

    \vspace{1em}
    \item[] \textbf{Третья лабораторная работа:}
    \item реализована генерация матрицы пропускных способностей для ориентированного графа;
    \item реализована генерация матрицы стоимостей для ориентированного графа;
    \item реализован поиск максимального потока алгоритмом Форда--Фалкерсона;
    \item реализовано вычисление потока минимальной стоимости величины $\left\lfloor 2 / 3 \cdot \text{max} \right\rfloor$;

    \vspace{1em}
    \item[] \textbf{Четвёртая лабораторная работа:}
    \item реализовано вычисление числа остовных деревьев неориентированного графа по матричной теореме Кирхгофа;
    \item реализовано построение минимального по весу остова алгоритмом Краскала;
    \item реализованы кодирование остова кодом Прюфера с сохранением весов рёбер и его декодирование;
    \item реализован поиск максимального независимого множества рёбер исходного графа и полученного остова;

    \vspace{1em}
    \item[] \textbf{Пятая лабораторная работа:}
    \item реализована проверка неориентированного графа на эйлеровость;
    \item реализованы модификация графа с сохранением связности и вывод сведений о выполненных изменениях;
    \item реализовано построение эйлерова цикла;
    \item реализовано построение минимального остова алгоритмом Краскала;
    \item реализованы получение и вывод фундаментальной системы разрезов;
    \item реализовано получение других разрезов из фундаментальных с помощью операции симметрической разности.
\end{enumerate}

\subsection*{Достоинства реализации}

\begin{itemize}
    \item программа написана в объектно-ориентированном стиле и имеет модульную структуру, поэтому классы графа, матрицы, генератора и консольного интерфейса можно изменять и проверять независимо;
    \item для каждой лабораторной работы используется единое меню, из которого можно последовательно вызывать все относящиеся к ней методы;
    \item вместе с итоговыми значениями программа выводит дополнительные данные, например матрицу смежности при построении фундаментальной системы разрезов, что упрощает проверку полученного результата.
\end{itemize}

\subsection*{Недостатки реализации}

\begin{itemize}
    \item матричное представление требует $O(p^2)$ памяти независимо от числа рёбер, поэтому неэффективно для больших разреженных графов;
    \item консольное представление матриц и других данных графа усложняет работу с большими графами, содержащими, например, 30 и более вершин;
    \item параметры распределения заданы в коде как константы, поэтому их нельзя изменить из пользовательского интерфейса.
\end{itemize}

\subsection*{Масштабируемость}

\begin{itemize}
    \item можно реализовать ввод параметров распределения пользователем, что позволит настраивать характеристики генерируемых графов без изменения кода;
    \item можно реализовать графический пользовательский интерфейс, например с помощью Qt, для визуализации графов и более удобного выбора операций;
    \item можно хранить граф в виде списка смежности и адаптировать для такого представления отдельные алгоритмы, что позволит сократить затраты памяти и повысить эффективность их работы на разреженных графах.
\end{itemize}

Таким образом, поставленные в лабораторных работах задачи выполнены.
